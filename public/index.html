How to use {{placeholders}} — examples and image instructions

Write one article; the app replaces each placeholder with the selected site's saved information before creating its draft. These are not WordPress post tags or shortcodes.

Text and links

Text placeholders work in the title, Article HTML and excerpt. The values come from each site's personalization settings. To make a clickable link, put its URL inside a quoted href:

<p>Visit {{practice_name}} in {{city}}.</p>
<p><a href="{{appointment_url}}">Book an appointment</a>.</p>

Inline images

  1. Put {{image:exam-room}} between paragraphs in Article HTML.
  2. Find the exam-room image row below and click Choose File.
  3. Choose a JPEG, PNG or WebP file (up to 10 MB) and enter descriptive alt text.
  4. Run preflight, review the preview, then confirm draft creation.

The file stays local until draft creation. Then it uploads separately to each selected site and the placeholder becomes an image using that site's URL. Use a different key for each additional image. Repeating a key reuses its image. Alt text is literal text; placeholders inside alt text are not expanded.

<p>Welcome to our office.</p>
{{image:exam-room}}
<p>We look forward to seeing you.</p>

Do not wrap an image placeholder in an <img> tag. It creates the whole image element. Image placeholders belong only in Article HTML, outside HTML attributes.

Featured image

None leaves the featured image unset. Separate featured image adds its own file picker. Use inline: … reuses an article image as the featured image, without uploading it twice per site.

Names and custom fields

Use lowercase names. Text keys use letters, numbers and underscores, starting with a letter ({{office_hours}}). Image keys use letters, numbers and hyphens ({{image:exam-room}}). Keep featured for the separate featured-image slot.

Add a custom text key under personalization in config/sites.json for each target site, then use that key in your article. Keys ending in _url require HTTPS values. Values are plain text, not HTML or nested templates.

Missing or blank values block that site during preflight. Check spelling and site settings, then run preflight again. There are no default-value expressions or conditional tags. See docs/PLACEHOLDERS.md in the project for the full guide and troubleshooting table.
